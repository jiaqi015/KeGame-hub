# 我是王牌资产顾问 · 玩法说明

最后更新：2026-04-21

这份文档回答的是：

- 这个游戏怎么玩
- 一局里你每天在做什么
- 先看哪些信息、先做哪些动作
- 怎么判断自己这局打得好不好

这份文档不回答：

- 底层分数公式每一项怎么计算
- 某个 repository 或接口怎么实现
- 某个组件怎么拆

如果你要看设计定位，请读 [docs/selling-houses-game-positioning.md](/Users/jiaqi/Documents/开放日测算/docs/selling-houses-game-positioning.md)。
如果你要看整体架构，请读 [docs/selling-houses-total-design.md](/Users/jiaqi/Documents/开放日测算/docs/selling-houses-total-design.md) 和 [docs/selling-houses-domain-architecture-v1.md](/Users/jiaqi/Documents/开放日测算/docs/selling-houses-domain-architecture-v1.md)。

## 一句话先讲明白

这不是“点技能攒数值”的小游戏，而是一局围绕多套房源做经营判断的策略游戏。

你扮演的是资产顾问。你不是来把每个按钮都点一遍，而是要在有限天数、有限精力、有限推广金里判断：

- 哪套盘最值得先救
- 哪套盘可以继续压资源
- 哪套盘应该靠开放日拉热
- 哪套盘该先稳业主，再谈价格
- 哪些客户值得推进到带看、报价、谈判

## 你的目标是什么

你的目标不是“把所有盘都打满分”，而是：

1. 把关键房源守住
2. 把值得打的盘推到更好的收尾
3. 不要让核心盘在竞品压力或业主失去耐心时失守
4. 在整局结束前，把资源尽量换成成交、好收尾和更好的复盘结果

简单说：

- 有些盘要保
- 有些盘要冲
- 有些盘要接受一般收尾
- 真正糟糕的是核心盘坏收尾，或者你因为节奏失控把整组盘一起拖崩

## 开局怎么开始

进入这条线后，第一步不是直接经营，而是先选难度，再决定打标准局还是随机局。

你会看到 6 档难度：

- `热身`
- `入门`
- `标准`
- `进阶`
- `高压`
- `极限`

每档难度都提供两种开局方式：

- `进入标准局`
  先打一局这档最典型的局面，适合熟悉这档的节奏
- `开启随机局`
  用这一档的难度规则随机生成一局新环境，适合刷手感和复盘判断

开始页会给你看：

- 这档难度的气质
- 标准局名称和主题
- 这局大概几套房、多少天节奏
- 这档最典型的压力

如果你第一次玩，建议这样选：

- 想先熟手感：`热身` 或 `入门` 的标准局
- 想体验完整拉扯：`标准` 这一档的标准局
- 已经知道规则，想吃判断：`进阶` 往上

## 一局大概是什么节奏

一局有明确的经营周期，通常在 17 到 26 天左右，不同难度和剧本会变。

你每天都在做三类事：

1. 看今天盘面发生了什么
2. 决定先处理哪套房、哪批客户、哪种关系问题
3. 用动作把局面往更好的方向推，然后结束今天或直接推进一周

每天最重要的不是“做满动作”，而是“做对顺序”。

## 你每天进来先看哪里

最稳的读盘顺序是：

1. `经营概览`
2. `房源管理`
3. `准客池`
4. 需要时再看 `商圈动静`
5. 最后回 `活动` / 复盘

### 1. 经营概览

这是你每天的第一屏。

这里最值得先看的是：

- `今日事实`
  看今天有哪些变化真的发生了
- `当前焦点`
  系统会告诉你今天最值得盯的房源或问题
- `风险变化`
  看今天最危险的地方在哪
- `资源状态`
  看今天还有多少精力、还剩多少天
- `盘型结构`
  看核心盘、重要盘、普通盘的结构有没有开始失衡

如果你只看一眼就想开干，至少先看这三样：

- 今天最该盯哪套盘
- 今天最危险的风险是什么
- 今天资源够不够支撑高成本动作

### 2. 房源管理

这是你真正做决策的主战场。

你会在这里看到：

- 房源列表
- 每套房当前阶段
- 剩余窗口
- 信任、热度、当前状态
- 业主画像
- 这套盘的准客池和后段机会
- 可执行动作

你可以把这里理解成：

- 左边是“今天先看哪套盘”
- 右边是“这套盘现在最该怎么处理”

### 3. 准客池

这里看的是客户与潜在机会，不只是“已有客户”，也包括“待确认客户”和市场信号。

重点看：

- 活跃机会有多少
- 哪些机会已经进入后段
- 哪些客户还只是影子机会
- 客户对应的是哪套房

准客池厚，不代表你稳了。
真正有价值的是：

- 有没有后段客户
- 有没有高质量客户
- 有没有客户快流失了

### 4. 商圈动静

这里适合在你觉得“怎么突然难卖了”“怎么客户都慢了”“为什么竞品开始抢节奏”时看。

你会看到：

- 市场异动
- 竞品压力
- 共享客户压力
- 潜在需求信号

这块不是让你天天看，而是在盘面突然失真时帮助你判断：

- 是你没做好
- 还是市场真的变了

### 5. 活动 / 复盘

这里更适合用来回看：

- 最近发生了什么
- 为什么今天突然有这个结果
- 哪个决策带来了后续连锁反应

## 你手里有哪些资源

这局最重要的资源不是只有“动作次数”，而是三种一起看：

### 1. 精力

- 每天能做多少动作，主要由精力决定
- 精力不够，就算你知道该干什么，也做不完
- 不同星期几的节奏不一样，系统会给你当天主题和精力感受

这意味着：

- 不是所有日子都适合做重动作
- 有些动作应该留到更关键的一天
- 快到见底时，要优先做最值钱的动作

### 2. 推广金

- 高成本动作会消耗推广金
- 典型高成本动作包括投放和开放日
- 每周会固定补给一轮推广金
- 成交后还会按规则返投一部分

这意味着：

- 不要把推广金全砸在看起来热闹但不一定有效的地方
- 推广金更适合用来解决“池子薄、热度不够、需要集中起量”的问题
- 如果余额太低，后面会很难做高成本动作

### 3. 时间

- 每局有最大天数
- 天数到了，游戏就会结算
- 有些房源自己的窗口也更短

这意味着：

- 不是所有盘都值得慢慢打磨
- 窗口短的盘要更早做判断
- 时间越往后，错一个顺序的代价越大

## 你能做哪些动作

当前动作分成 4 类。

## 1. 面访反馈

适合解决：

- 关系不稳
- 业主不理解你在干嘛
- 需要先建立经营共识

典型动作：

- `首次面访`
- `周度反馈`
- `深度诊断`

什么时候先做这类动作：

- 业主信任快掉了
- 很久没给业主有效反馈
- 你其实知道问题在哪，但业主还没被你讲明白

## 2. 营销推广

适合解决：

- 客户池太薄
- 热度不够
- 需要把流量拉起来
- 需要把客户推进到带看

典型动作：

- `精修卖点`
- `小红书推广`
- `经纪人投放`
- `私域转介绍`
- `开放日`
- `安排带看`

这里最容易犯的错是：

- 池子薄就只会砸推广
- 但房源讲法、价格站位、业主配合都没跟上

结果就是：

- 来了一些人
- 但留不住、推不深、也收不住

## 3. 定价建议

适合解决：

- 盘卖不动，本质矛盾已经是价格
- 业主还没意识到价格站位的问题
- 需要先摸清业主真实心理价

典型动作：

- `定价建议`
- `询问心理价`
- `商讨挂牌价调整`

这类动作的重点不是“你敢不敢砍价”，而是：

- 你有没有足够证据
- 业主对你有没有足够信任
- 现在是不是谈价格的时点

## 4. 斡旋谈判

适合解决：

- 已经出现后段客户
- 需要把客户和业主真正推上成交桌
- 想把局面收口

典型动作：

- `建议参与诚意卖`
- `邀请和客户谈判`

常见误区是：

- 还没到后段，就急着谈判
- 或者终于有后段客户了，却还在别的盘上分神

## 新手最容易用错的动作

### 开放日

开放日是高成本动作，不是“只要没思路就点一下”的万能按钮。

更适合做开放日的情况：

- 房源本身还值得打
- 你需要集中拉一波热度
- 这套盘已经有一定承接基础

不太适合的情况：

- 价格站位明显有问题
- 业主关系还没稳住
- 你只是因为今天没别的主意

### 经纪人投放 / 小红书推广

这两类动作更像“补池子”和“补热度”。

它们能帮你：

- 快一点来客
- 扩一批待确认客户

但它们不能替代：

- 房源判断
- 定价沟通
- 带看后的推进

## 每天到底该怎么走

如果你想要一条最稳的日常玩法流程，可以照这个顺序来：

### 第一步：先读盘，不要急着点

先看：

- 今天焦点是谁
- 今天最大的风险是什么
- 今天资源够不够

### 第二步：找今天最不能拖的盘

优先级通常是：

1. 核心盘里快出事的
2. 有后段客户但快流失的
3. 业主关系在掉、窗口又短的
4. 值得用推广金再推一把的盘

### 第三步：判断这个盘的问题到底在哪一层

最常见的四种问题：

- 业主不稳
- 客户池不够
- 价格站位不对
- 已经到后段但没有收口

### 第四步：动作只解决一个核心矛盾

不要一口气想“这一套盘今天全部解决”。

更有效的思路是：

- 今天先稳业主
- 或今天先补池子
- 或今天先谈价格
- 或今天先把后段客户推进

### 第五步：再决定要不要结束今天

如果你还有精力和预算，不代表一定要继续做动作。

应该看：

- 继续做是不是边际收益还高
- 还是应该把资源留给明天或本周更关键的一天

## 怎么判断一套房现在值不值得救

可以用一个最实用的 5 问法：

1. 这套盘是谁
   先看它是不是核心盘、重要盘，还是普通盘
2. 这个业主怎么样
   信任还在不在，耐心是不是快掉到底
3. 这套货能不能打
   房源竞争力、卖点、热度、价格站位是不是还值得继续投
4. 这套盘的准客池厚不厚
   有没有活跃客户，有没有后段客户，有没有高质量机会
5. 这周我得处理什么
   现在最急的是关系、热度、价格，还是成交推进

如果五问下来你发现：

- 关系崩
- 价格硬
- 池子薄
- 时间短

那通常不是“再多做一点动作”就能解决，而是要判断值不值得继续押资源。

## 怎么才算打得好

这游戏最终会给你结算，不只看单一分数，而是看三类结果：

- 能力分
- 守盘分
- 满意分

最终你会看到：

- 总评等级
  - 例如 `王牌`、`漂亮`、`过线`、`失守`
- 房源结局分布
  - 好收尾 / 一般收尾 / 坏收尾
- 得分拆解
- 每套房的最终收尾
- 这局打得好的地方
- 下次该复盘什么

最健康的目标不是“每套盘都成交”，而是：

- 关键盘别坏收尾
- 核心盘别失守
- 值得打的盘打成好收尾
- 你能看懂自己是赢在什么判断上

## 常见失败方式

### 1. 什么都想救

看起来很努力，但实际是：

- 资源被摊薄
- 每套盘都差一口气
- 最后没有一套真正打透

### 2. 只顾拉热度，不顾承接

只做推广、不做判断，结果是：

- 进来很多机会
- 但推进不深
- 最后只是热闹，不是收口

### 3. 太晚才谈价格

如果价格已经是主矛盾，却一直拖着不谈，最后通常会变成：

- 客户推进不上去
- 业主耐心下降
- 时间窗口被白白耗掉

### 4. 核心盘失守

这类失败最伤。

因为它通常意味着：

- 你没有把最重要的盘放在最前面
- 或者你太晚才意识到它在掉节奏

## 给第一次玩的建议

如果你是第一次进这条线，推荐这样玩：

1. 先打 `入门` 或 `标准` 的标准局
2. 每天先看 `经营概览`
3. 再去 `房源管理`
4. 今天只盯 1 到 2 套最关键的盘
5. 开放日不要乱开
6. 推广金优先留给真正值得打的动作
7. 一局打完一定看结算页，不要只看分数

尤其要记住：

- 你不是输在“不会点按钮”
- 大多数时候你是输在“顺序错了”或者“押错了盘”

## 一句话复盘模板

每打完一局，你可以只问自己四个问题：

1. 我这局最早做对的判断是什么
2. 我最晚意识到的问题是什么
3. 我把资源浪费在哪类动作上了
4. 如果重来一局，我第一天先保哪套盘

如果你能回答这四个问题，这局就没有白打。
