# 我是王牌资产顾问 · 游戏定位

最后更新：2026-04-17

这份文档只回答一件事：

- 这条线本质上是什么游戏

不回答：

- 某个按钮怎么摆
- 某个参数具体是多少
- 某个接口怎么接

这些都应该在这份定位之下展开。

## 一句话定义

这是一个以房源经营、局势判断和资源取舍为核心的策略游戏。

玩家不是来“学习一套知识”，而是来打一局：

- 在有限时间里判断先救谁
- 在多个业主和多个盘之间分配注意力
- 在关系、价格、热度和竞争之间找平衡
- 接受有些盘该保，有些盘该放

学习会发生，但那只是副产物，不是主产品。

## 核心玩法幻想

玩家进入这条线后，应该感觉自己是在：

- 接手一个正在变化的局面
- 不是全知的，但必须比局势早一步判断
- 不能什么都做，只能做最重要的事
- 做对一两个决定，就能把局势扳回来
- 做错关键一步，整组盘都会跟着失控

这条线最重要的不是“我学会了什么”，而是：

- 这局我差点翻车，但我稳住了
- 这一步我赌对了
- 我知道自己输在哪
- 我还想再开一局

## 它不是什么

它不是：

- 培训系统
- 教学软件
- 带包装的伪游戏
- 房产知识答题器
- 用随机题目驱动的闯关页

如果某个设计让玩家更像“上课”，而不像“打局”，那就是方向偏了。

## 设计北极星

后续所有设计，都应该优先服务这四件事：

1. 局面感
   玩家一眼知道这一局哪里难、哪里乱、哪里值得赌。
2. 取舍感
   玩家不能什么都做，必须做选择。
3. 后果感
   每个决定都要有代价和外溢。
4. 再来一局冲动
   打完后想再开，不是因为“还没学会”，而是因为“这局还能打得更好”。

## 核心乐趣

这条线的乐趣不该来自“动作多”，而该来自“判断值钱”。

建议明确四种主乐趣：

### 1. 救火

- 一套盘快崩了
- 你抢在失控前把它稳住

### 2. 押注

- 资源不够全救
- 你判断哪套盘值得押

### 3. 连锁

- 一次动作不只影响一套房
- 会牵动整组竞争盘

### 4. 收口

- 局面不是无限展开
- 后期要把前面的判断兑现成结果

## 失败体验也必须像游戏

失败不是“没学会”，而应该是：

- 贪了
- 慢了
- 判断错优先级
- 被竞品带了节奏
- 想全救，结果全都没救好

只要失败原因能被玩家复盘成“这局我输在某个判断”，那失败就是健康的。

如果失败更像“系统规则没说清楚”，那就是设计失败。

## 六档难度的本质

六档难度不是六层课程，而是六种游戏体验。

### 热身

关键词：

- 顺手
- 宽松
- 找节奏

玩家感受：

- 不容易立刻乱
- 更适合进入状态

这一档的乐趣：

- 很快找到手感
- 感觉自己能掌控局面

### 入门

关键词：

- 清晰
- 友好
- 开始分心

玩家感受：

- 开始有取舍
- 但不会马上被惩罚到抬不起头

这一档的乐趣：

- 明白这游戏的基本爽点

### 标准

关键词：

- 平衡
- 拉扯
- 开始联动

玩家感受：

- 顾这边会漏那边
- 开始像真的在经营一组盘

这一档的乐趣：

- 做对优先级会很舒服

### 进阶

关键词：

- 碎
- 快
- 吃判断

玩家感受：

- 错误开始明显外溢
- 不是不会操作，而是不知道先动哪

这一档的乐趣：

- 通过更早判断把混乱压住

### 高压

关键词：

- 紧
- 脆
- 不能贪

玩家感受：

- 不是每套盘都能保
- 要开始接受放弃和止损

这一档的乐趣：

- 在高压力下保住真正重要的盘

### 极限

关键词：

- 低容错
- 高耦合
- 残局识别

玩家感受：

- 局面很吵
- 不靠勤奋，靠判断

这一档的乐趣：

- 在几乎要崩的局面里做对关键选择

## 开始页应该传达什么

开始页不是说明书，而是选模式页面。

玩家在开始页第一眼应该读到的不是：

- 你将学习什么
- 系统将教你什么

而应该是：

- 这一档是什么气质
- 这一档大概有多乱
- 这一档的典型压力是什么
- 我是先打标准局，还是直接刷随机局

所以开始页的任务只有三个：

1. 让玩家选难度
2. 让玩家理解这一档的味道
3. 让玩家决定打标准局还是随机局

## 标准局和随机局的定位

### 标准局

标准局的作用不是“示范教学”。

标准局的作用是：

- 让玩家快速理解这一档的气质
- 给这一档一个清晰记忆点
- 建立对这档玩法的预期

它更像：

- 经典开局
- 推荐开局
- 这档最像它自己的那一局

### 随机局

随机局的作用不是“自动出题”。

随机局的作用是：

- 增加重玩性
- 保持同难度下的新鲜感
- 让玩家反复刷同一档的手感

关键要求不是绝对随机，而是：

- 每局都新
- 但仍然保留这一档的性格

## 文案口径

这条线以后所有文案都应该使用游戏语言，不使用培训语言。

### 推荐词

- 一局
- 开局
- 局面
- 节奏
- 压力
- 风险
- 赢法
- 取舍
- 收口
- 翻盘
- 标准局
- 随机局
- 推荐开局
- 核心压力
- 这一档更像什么

### 禁用词

- 教学
- 教学重点
- 学习目标
- 课程
- 训练营
- 教案
- 练习题
- 上手教程
- 示范教学

如果确实要解释，也应该写成：

- 这一局最难的是
- 这一档主要压力在
- 这一档更吃哪种判断

不要写成：

- 这一档教你什么

## 系统设计的判断标准

以后判断一个功能要不要做，可以先问四个问题：

1. 它有没有增强局面感？
2. 它有没有逼出取舍？
3. 它有没有带来明确后果？
4. 它会不会提升“再来一局”的冲动？

如果四个问题都答不上来，这个功能大概率不是核心。

## 生成系统应该服务什么

生成系统不是为了显得智能。

生成系统真正要服务的是：

- 每档难度有稳定气质
- 每局有新鲜感
- 新鲜感不破坏这档玩法味道
- 玩家的输赢能复盘到判断上

所以生成器的目标不是“随机得很聪明”，而是：

- 稳定地产生好玩的局面

## 版本优先级

如果只按游戏定位做优先级，应该先做：

1. 六档难度的气质更鲜明
2. 标准局更有记忆点
3. 随机局更有重玩性
4. 局内反馈更有情绪回报
5. 失败复盘更像“输了这一局”，而不是“答错了题”

不该优先做：

- 更重的说明文字
- 更像课程的引导
- 讲知识点的长描述

## 一句收束

这条线不是“用游戏包装教学”。

它应该是：

- 一个本身成立的策略游戏

玩家先觉得它好玩、想赢、想再来一局。

至于理解经营逻辑，那应该是玩家玩进去之后自然得到的东西。
