## 三条业务线的成熟度

### 1. 多模型PK

- 已经接入统一入口。
- 覆盖激活、模型列表、对比和流式对比。
- 不是当前主要开发战场，但仍是产品入口的一部分。

### 2. 开放日选址

- 当前是完成度最高、链路最闭环的一条业务线。
- 主流程已经收敛为“两步式”：
  - 上传并预览数据
  - 进入工作台做测算、参数调整、方案和历史操作
- 前端工作台在 `src/open-day/`，后端职责和领域演进主要在 `api/` 与 `modules/open-day/`。
- 相关后端能力已经覆盖：
  - workbook 解析
  - 参数目录
  - 测算评分
  - 历史快照
  - 方案模板
  - 方案版本列表

### 3. 我是王牌资产顾问

- 已经从单机玩法明显走向“云存档、云同步、排行榜、剧本生成”的架构。
- 主目录在 `src/selling-houses/`。
- 已经存在：
  - `Neon` 数据库方向
  - run / leaderboard / scenario 相关接口
  - 云同步状态与客户端封装
  - 本地自对抗 / lab / verify 脚本
- 这条业务线仍在快速演进，代码形状和数据模型都可能继续调整。
